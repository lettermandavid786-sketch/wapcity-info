        Внешние архивы для ручной проверки

          Как пересобрать

          python3 scripts/fetch_wayback.py                 # индекс + последняя версия каждого URL
python3 scripts/fetch_wayback.py --versions 0    # все различающиеся версии
python3 scripts/build_site.py                    # archive/ → docs/archive.html (этот навигатор)
python3 scripts/extract_forum.py                 # → docs/forum.js (форум, люди, история)
          Страницы WML (WAP 1.x) преобразованы в HTML: карточки <card> показаны блоками, <anchor>/<go> и <do> — ссылками. Формы, скрипты и пароли отключены. Кодировка определяется по заголовкам, а для старых страниц без них — эвристикой (windows-1251 / KOI8-R).
