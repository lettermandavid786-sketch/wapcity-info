wapForum
О СЕРВИСЕ
Сервис «wapForum» является бесплатным сервисом общения, предлагает пользователям общаться с абонентами различных операторов на различные темы в предустановленных рубриках форума посредством мобильного телефона. У Вас есть возможность:
- Зарегистрироваться в сервисе, указав только ник и пароль
- Читать сообщения абонентов из базы форума
- Писать (отправлять) свои сообщения в базу форума
- Создавать свои темы для общения с другими абонентами
- Получить помощь по использованию Форума
