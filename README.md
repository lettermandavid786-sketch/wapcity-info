# wapcity-info — архив forum.wapcity.ru

Восстановленная из веб-архивов копия WAP-форума **forum.wapcity.ru** в виде
интерактивного сайта: страницы форума можно листать прямо в браузере, ссылки
между ними работают, WML-страницы (WAP 1.x) показаны так, как их видел телефон.

**Открыть:** `docs/index.html` (работает прямо с диска, сервер не нужен) или
GitHub Pages: *Settings → Pages → Deploy from a branch → `/docs`*.

## Что внутри сайта

| Раздел | Что показывает |
|---|---|
| **Обзор** | сводка, график снимков по месяцам (клик по столбцу — страницы за месяц), самые связанные страницы, типы страниц, главная во времени |
| **Навигатор** | поиск по названию/адресу и по тексту, фильтры по типу и году, просмотр страницы в «телефоне» или во всю ширину, все версии одной страницы, назад/вперёд, переход в Wayback |
| **Карта сайта** | дерево адресов: хост → путь → параметры (`index.php → ?f / ?t`) |
| **Все URL** | каждый адрес домена из индекса Wayback, включая не скачанные |
| **Источники** | что запрашивалось, когда, сколько найдено; ссылки на другие архивы |

Горячие клавиши в навигаторе: `/` — поиск, `j` / `k` — следующая / предыдущая страница.

## Как это собирается

```
scripts/fetch_wayback.py   индекс CDX Wayback Machine → archive/ (сырые страницы + manifest.jsonl)
scripts/build_site.py      archive/ → docs/ (index.html, data.js, search.js, p/<id>.html)
scripts/site_template/     шаблон навигатора и стили архивных страниц
.github/workflows/archive.yml   всё это на GitHub Actions с автоматическим продолжением
```

- Скачиваются оригинальные ответы (`id_`), без панели Wayback.
- Кодировка: из заголовков / `<?xml encoding?>` / `<meta charset>`, иначе эвристика windows-1251 vs KOI8-R.
- WML → HTML: `<card>` — блоки, `<anchor><go/>` и `<do>` — ссылки, переменные `$(var)` убираются.
- Ссылки на сохранённые страницы ведут на **ближайший по времени** локальный снимок; параметры сессии (`sid`, `PHPSESSID`, `rnd` …) при сопоставлении игнорируются. Остальные ссылки открываются в Wayback (помечены ↗).
- Скрипты, формы и поля паролей отключены.

### Локально

```bash
python3 scripts/fetch_wayback.py --versions 3   # до 3 версий каждой страницы, распределённых по времени
python3 scripts/build_site.py                   # → docs/index.html
```

Повторный запуск продолжает с места остановки. Полезные флаги: `--versions 0` (все версии),
`--domain wapcity.ru` (другой/дополнительный хост), `--assets` (картинки), `--max-minutes N`.

### На GitHub Actions

Workflow **Archive forum.wapcity.ru** запускается при изменении скриптов или вручную
(*Actions → Archive forum.wapcity.ru → Run workflow*). Каждый прогон качает до 5 часов,
коммитит `archive/` и `docs/` и, если скачано не всё, сам запускает следующий прогон.
